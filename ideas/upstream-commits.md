- Upstream: [pigmonkey/spark](https://github.com/pigmonkey/spark), an Arch Linux Ansible provisioning project.
- The last upstream change reflected in this repository is [`4bed7b0e`](https://github.com/pigmonkey/spark/commit/4bed7b0e4155e3838ff4dc480a561991eb2b71c9) (`install explicit i3 packages`, 2018-03-27). The source history was rewritten during the 2018 import, so Git does not report a shared SHA/merge-base.
- The local project was created on 2018-04-03, and later commits moved it from Spark’s generic i3/X11-oriented playbook into a personal Arch desktop/laptop setup. The current [README](./README.md) and [Ansible playbook](./ansible/playbook.yml) describe Sway/Wayland, custom roles, and machine-specific policies.
- Reviewed **547 commits** reachable from upstream `master` after the fork point through [`c556cb60`](https://github.com/pigmonkey/spark/commit/c556cb601199e737dffd2bcdc4923c8033dcdb99) (latest commit dated 2026-09-29). Each row uses the commit subject as a concise change summary and links to the full commit.

## Recommendation summary

- **Do not cherry-pick the upstream series wholesale.** The two projects now have different role layouts, desktop stacks, package choices, and hardware assumptions.
- Best candidates for **manual adaptation**, not direct application: `cd6d972f` (package-source drift checker; related to [package recovery](./ideas/ideas-01-package-recovery.md)) and `f422450d` (linting; related to [configuration validation](./ideas/ideas-14-config-validation.md)).
- Optional policy reviews: `48a32e5e` and `5ef452cd` (NetworkManager MAC randomization/privacy). These require a deliberate networking/privacy choice.
- Every other commit is marked below as not directly applicable, merge-only, or a reference for an existing but diverged local role. This is not a request to change any configuration now.
